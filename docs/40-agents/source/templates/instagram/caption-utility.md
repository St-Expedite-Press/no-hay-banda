# Template: Caption Utility (Discovery/Recommendation)

**Objective:** Help the audience find films matching a specific need or interest. Optimized for saves — the audience should want to return to this post when they are looking for their next watch.

**Structure:** Lead with the audience's need, then deliver a list or recommendation grounded in actual product data. CTA to the browse filter or movie page.

**Required inputs:**
- The specific audience need or discovery intent being addressed
- 2–4 film recommendations with newshow.biz URLs (or a browse filter URL that covers the need)
- Source ref confirming each film appears in the relevant filter results

**Skeleton (list format):**

```
[Audience need framed as a question or observation — 1 sentence]

[Film 1 title, year] — [1-line observation grounded in data]
[Film 2 title, year] — [1-line observation grounded in data]
[Film 3 title, year, optional] — [1-line observation]

All on newshow.biz. [browse filter URL or individual movie URLs]

#[need-adjacent hashtag] #[discovery tag]
```

**Skeleton (single recommendation format):**

```
[Audience need]

[Film title, year] [specific observation grounded in the film's actual profile — 2–3 sentences]

Full profile + where to watch: newshow.biz/movies/[film-slug]

#[tag] #[optional second tag]
```

**Anti-fabrication rule:** Every film listed must actually exist in the newshow.biz catalog and match the filter criteria. Do not list a film as matching a filter unless the source data confirms it.

**Prohibitions:**
- No em dash
- No fabricated filter results or made-up films
- Kakusu Protocol on all copy
- Source refs required for every recommendation
