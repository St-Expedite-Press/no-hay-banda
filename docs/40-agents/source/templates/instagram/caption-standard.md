# Template: Caption Standard (Single Image)

**Objective:** Accompany a single film image or graphic with a caption that drives discovery and saves/shares. Instagram's algorithm rewards saves — anchor the copy to something the audience will want to return to.

**Structure:**
- Line 1: Strong opener, 125 chars max. The hook that stops the scroll.
- Lines 2–4: Context. 2–3 sentences. Cinematic observation grounded in score data.
- CTA line: Direct action — where to find the film on newshow.biz.
- Hashtags: 5–10 relevant tags on a separate line (Instagram norm differs from X).

**Required inputs:**
- Film title, year, and category data from newshow.biz
- Source ref for any score claim
- The film's newshow.biz URL
- Image description (for caption coherence — do not fabricate image contents)

**Skeleton:**

```
[Hook — 125 chars max. Specific, surprising, or counterintuitive observation. No advocacy framing.]

[2–3 sentences grounding the observation in the film's actual analysis. What the film does structurally. What the scores reflect.]

Full profile at newshow.biz/movies/[film-slug]

#[genre] #[dimension] #[film-related tag] #[discovery tag] #[optional 5th tag]
```

**Prohibitions:**
- No em dash
- No fabricated character names, scenes, or plot points not sourced from the movie page
- No claims that scores are official or endorsed
- Kakusu Protocol applies — no advocacy framing
- Do not lead with an emoji (can include one inline, not as the first character)
- Source ref required for any score claim — return BLOCKED if data is unavailable
