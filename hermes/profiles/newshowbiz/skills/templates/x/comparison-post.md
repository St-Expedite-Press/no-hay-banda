# Template: Comparison Post

**Objective:** Surface two films that handle a shared theme or dimension differently. Drive discovery to both movie pages.

**Character limit:** 280

**Required inputs:**
- Film A title, year, and newshow.biz URL
- Film B title, year, and newshow.biz URL
- One specific shared dimension where their approaches differ (grounded in score data or written observations)
- Source evidence from both movie pages

**Skeleton:**

```
[Film A] and [Film B] approach [specific dimension] from opposite ends of the same question. [Observation grounded in source data — 1 sentence per film, no ranking, no advocacy.]

Both on newshow.biz. [Film A URL] / [Film B URL]
```

**Notes:**
- Do not declare a winner or assert one film is "better" on the dimension
- Both source refs must be present before this template is used — return BLOCKED if only one film's data is available
- The observation must be grounded in actual score data or written category analysis from the movie pages

**Prohibitions:**
- No em dash
- No fabricated scenes or character details
- No advocacy framing
- Hashtags optional — only if both films share a clear genre or dimension tag
